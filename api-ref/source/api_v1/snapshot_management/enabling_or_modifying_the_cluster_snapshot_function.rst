Enabling or Modifying the Cluster Snapshot Function
===================================================

Function
--------

This API is used to enable or modify the cluster snapshot function. Cluster snapshots enhance data protection and restoration capabilities for clusters. By storing a snapshot in an OBS bucket, you save a point-in-time copy of the cluster's data. By restoring this snapshot, you can restore the cluster to a previous state.

When enabling or modifying the cluster snapshot function, you can enable or disable automatic snapshot creation.

Calling Method
--------------

For details, see :ref:`Calling APIs <css_03_0077>`.

---
