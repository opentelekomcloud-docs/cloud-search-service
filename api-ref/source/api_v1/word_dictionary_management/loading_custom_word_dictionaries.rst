Loading Custom Word Dictionaries
================================

Function
--------

The word dictionaries of an Elasticsearch/OpenSearch cluster in CSS is used for word segmentation of text, enabling special words to be recognized during segmentation and facilitating text data search by keywords. For example, you can search by trending terms such as **xidapuben**. It also supports searching text data using synonyms based on a synonym dictionary. The analyzers used by CSS include the IK analyzer and the synonym analyzer. The IK analyzer has a main word dictionary and a stop word dictionary. The synonym analyzer has a synonym dictionary. The IK tokenizer supports **ik_max_word** and **ik_smart** segmentation policies. The synonym analyzer uses the **ik_synonym** segmentation policy. This API is used to load a custom dictionary stored in OBS. When the preset word dictionaries cannot meet the word segmentation requirements of the cluster, a custom dictionary can be used.

Calling Method
--------------

For details, see :ref:`Calling APIs <css_03_0077>`.

URI
---

POST /v1.0/{project_id}/clusters/{cluster_id}/thesaurus

Response Parameters
-------------------

**Status code: 200**

Example Requests
----------------

Enable and configure the word dictionary.

.. code-block:: text

   POST https://{Endpoint}/v1.0/{project_id}/clusters/4f3deec3-efa8-4598-bf91-560aad1377a3/thesaurus

   {
     "bucket_name" : "test-bucket",
     "main_object" : "word/main.txt",
     "stop_object" : "word/stop.txt",
     "synonym_object" : "word/synonym.txt",
     "static_main_object" : "word/staticMain.txt",
     "static_stop_object" : "word/staticStop.txt",
     "extra_main_object" : "word/extraMain.txt",
     "extra_stop_object" : "word/extraStop.txt"
   }
